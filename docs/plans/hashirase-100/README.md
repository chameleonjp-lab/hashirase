## 今回確定させる方向

ホーム画面で「①ドライビングゲーム」「②現実の物理に近い車両シミュレーター」を選びます。ホームでは3Dエンジンを読まず、選択後に共通部分と選んだモードだけを読み込みます。スマホとPCで入力・設定を分け、一般車は右側通行を守ります。スマホの標準運転は**タップした位置を起点にしたスワイプ操作**とし、固定のアクセル・ブレーキ・左右ボタンを主操作から外します。追跡パトカーは最大5台とし、増援時に5台いる場合は最後尾を退場させて新しい1台と入れ替えます。

フォルダを分けただけの状態から、**状態・物理・描画・操作・ルールを個別に検査し、交換できる状態**へ進めます。ゲームとシミュレーターを同じ処理の係数変更だけで済ませません。

| 1：独立した基礎を作る | T01〜T06 | 回帰試験、部品間の約束、2つの実行系、選択読み込み、端末別操作が動く |

各作業を原則1PRにします。全工程を1回の依頼で実装しません。並行開発は共有する型と設定を固定した後に、異なるファイルを担当する組合せに限ります。

## 決定事項と提案の区別

ホームの2択、選択側だけ読み込むこと、スマホ・PC対応、端末別設定、右側通行、追跡5台と最後尾入替、**スマホはタップ位置を起点としたスワイプ運転を標準操作とすること（U09）**はユーザーの決定事項です。
