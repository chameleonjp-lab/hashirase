# T05 ホーム・選択読み込み・終了とT06接続

作業ブランチは `feat/t05`。T03 #7（48508af）、T04 #8（c3419eb）、T06 #9（d351d14）のユーザーマージを確認し、最新のmainを取り込んだ。T05はT03/T04後に着手し、T06コードの統合は#9のマージ後に行った。

## 変更

- 新しいindexは目的の異なる2択。ゲームの実画面と、推定値の独立した直線シミュレーターを起動する。
- 静的ホームにはモード/Three/旧simulatorのプログラム・素材を含めない。モード、ローカルCSS/HTML、ゲーム描画/音を選択後にのみ取得する。両方向のネットワークをbuild-manifestの入力一覧で検査する。
- 世代番号/AbortSignal/ResourceScope、固定1/120秒とアプリだけのRAF。連打・変更・取消・戻る・失敗・終了で旧セッションを解放し、遅い結果を起動しない。
- 中断/再開/リセット/RESULT/ERROR。非表示や設定・操作説明で中断し、自動再開しない。過負荷は明示的に無効化し、リセットを案内。WebGL消失後も旧画面を廃棄して再試行。
- T06の実入力/設定を接続。感度、端末手動変更、mode別キー、音量/画質/単位/カメラ/揺れ/描画頻度/表示サイズを適用する。シミュレーターの未実装設定は表示しない。
- 旧ゲームの画面と機能はlegacy.htmlで原本検査を継続し、新入口にもアクション・コース・デモ・HP・得点等を残す。ミニマップは私有bitmapからimgへ転写し、DOMの描画canvasは1つ。

## 検査先行と修正

[REDの基盤8件](t05/logs/red-races.log)は必要なAPIがないため失敗し、[REDのホーム](t05/logs/red-home.log)は2択がないため失敗した。先にab18484へ保存した。資源解放、出力音量、表示port、RCS、過負荷、RESULT、ロード中の中断、依存監査の動的入口は追加のREDログを保存して実装した。

最初の実画面検査は[DOM canvasが2つ](t05/logs/red-real-app.log)を検出し、地図を残して修正。[実設定保存と失敗importの再試行](t05/logs/red-app-integration.log)、[停止中の旧ヘルプ閉じる](t05/logs/red-paused-dialog.log)、[縦横画面の説明と操作の重なり](t05/logs/red-layout-overlap.log)も再現して修正した。

[最初の通常検査](t05/logs/first-regression.log)は隔離ビルドの一時コピーに新しい表示用依存がなく失敗。元の不混入・再現性assertを全て残し、コピーする対象を追加した。この失敗後にアプリ再ビルドがされていない状態で実行した[追加検査の環境失敗](t05/logs/red-error-rcs-environment.log)はREDの証拠に数えない。アプリを再ビルドし、修正前の該当動作で[期待した失敗](t05/logs/red-error-rcs.log)（生URLの表示、RCSキー保持）を確認してから最終動作を検査した。

通常検査は104 Node（単体69 / 結合25 / 物理10）。生成一致、原本117ID、依存境界も含む。[ログ](t05/logs/regression.log)。ブラウザの結果は[t05/logs/browser-regression.log](t05/logs/browser-regression.log)、ビルド入力一覧はCI artifactへ保存する。独立最終レビューとCIの最終結果は追記する。
